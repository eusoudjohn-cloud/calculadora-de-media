Calculadora de Média Escolar

Sobre o projeto

Este projeto consiste em uma pequena página web interativa desenvolvida como atividade prática de introdução ao desenvolvimento web, utilizando HTML, CSS e JavaScript.

A aplicação permite informar o nome de um estudante e suas três notas, calcular a média aritmética e apresentar o resultado na tela, indicando se o estudante atingiu a média mínima para aprovação.

Objetivos

Desenvolver uma página web com estrutura HTML organizada.

Aplicar estilos CSS para melhorar a apresentação visual.

Utilizar variáveis e funções em JavaScript.

Implementar um botão com evento de clique por meio do envio de um formulário.

Realizar validações de dados inseridos pelo usuário.

Calcular e exibir resultados dinamicamente na página.

Tecnologias utilizadas

HTML5: estruturação do conteúdo e criação do formulário.

CSS3: estilização dos elementos e adaptação para diferentes tamanhos de tela.

JavaScript: validação dos campos, cálculo da média e atualização do conteúdo da página.

Funcionalidades

Campo para inserir o nome do estudante.

Campos para informar três notas.

Validação para aceitar notas entre 0 e 10.

Cálculo automático da média aritmética.

Exibição da média calculada.

Indicação de aprovação quando a média é igual ou superior a 7,0.

Mensagens de orientação quando os dados são inválidos.

Como executar o projeto

Baixe ou clone este repositório.

Localize o arquivo index.html.

Abra o arquivo em um navegador de internet.

Informe o nome do estudante e as três notas.

Clique em Calcular resultado para visualizar a média.

Não é necessário instalar programas ou bibliotecas adicionais.

Publicação

O projeto pode ser publicado gratuitamente pelo GitHub Pages, utilizando um repositório público compatível com o serviço.

Após configurar a publicação em Settings → Pages, o endereço público do site poderá ser compartilhado.
